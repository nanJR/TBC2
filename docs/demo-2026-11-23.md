# Demo sheet: Phase II evaluation (23 Nov 2026)

Everything on screen is simulated: synthetic patients, ABHA records, ASHA names and
X-ray van schedules. The cough and X-ray scores come from the real models.

## Start

```bash
./scripts/dev.sh          # http://localhost:3000
```

**Login is on** (Supabase). Sign in at `/login`:

| Portal | Email | Password |
| --- | --- | --- |
| Counter (pharmacist) | `counter.hanur@example.com` | `DEMO_PASSWORD_PRACTITIONER` in `services/api/.env` |
| ASHA portal | `asha.hanur@example.com` | `DEMO_PASSWORD_ASHA` in `services/api/.env` |
| Both portals (admin) | `coordinator.tbc2@example.com` | `DEMO_PASSWORD_COORDINATOR` in `services/api/.env` |

Use two browser windows (one normal, one private) to show both roles side by side.
Data is saved in Supabase, so it survives restarts. No network on the day? Comment out
`SUPABASE_SECRET_KEY` in `services/api/.env` and the two lines in `apps/web/.env.local`,
then restart: everything runs in memory without login.

If colours or layout look stale: stop it, `rm -rf apps/web/.next`, start again, and
press Ctrl+Shift+R in the browser.

## Click path (about 4 minutes)

1. **Home** → Counter Portal → sign in as the pharmacist.
2. **Counter**: ABHA `91-5528-7340-1196`, tick consent, Fetch History. Tick
   "Cough > 2 Weeks". Upload `PID_108A_10_codec.wav`. Get Risk Score → **67%, High
   Risk, Refer for NAAT Test**. Tick contact consent → Forward to ASHA. Show Print
   Referral Slip.
3. **ASHA Portal** (sign in as the ASHA in the other window): point out Suggested by TBC² (approve one: nothing is sent without
   approval). Open the new case at the top of Forwarded Cases:
   Reached → Sputum Collected → Book the van → upload `tb5494.jpg` (**99%**) → Get
   Combined Risk Score (**99%, NAAT**) → NAAT "MTB Detected, RR Not Detected" → Start
   Treatment (any MO name, PHC Ramapura, 50–64 kg, tick notified).
4. Open the new patient: Month 1 of 6, Intensive Phase, record today's dose, record an
   IsoScreen test (12 hours since dose).
5. Show a high-risk patient in Likely to Stop Treatment (reasons, missed-dose ladder,
   IsoScreen "INH Not Detected").
6. Toggle dark mode.
7. Security (if asked): data is in Supabase Mumbai; the browser key can't read any
   table (row-level security); each role sees only its portal; every change is in the
   audit log; ABHA numbers are stored only as hashes; uploads are never stored.

## Honest numbers to quote

- X-ray: 95% accuracy, 90% sensitivity on a deduplicated JU-TB test; outside tests
  AUROC 0.67 (Montgomery) and 0.78 (Shenzhen). Next: fine-tune on mixed sources.
- Cough: clinic-only (TBscreen) cross-validated AUROC 0.67. It may only add an X-ray,
  never a NAAT. Next: retrain on CODA TB once access is approved.
- Combined score: a simple rule (the higher of the two rescaled scores), not a trained
  fusion model: no dataset has both a cough and an X-ray for the same person.
- Dropout risk: rule-based on synthetic data; it only shows the pipeline works.
